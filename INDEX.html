Cocreación de modelos de negocio

INNOVA-CANVAS

Tablero de los nueve bloques de la ontología de Osterwalder para trabajo simultáneo de un equipo real: aportes sobre el tablero, chat, blog por bloque, relaciones argumentadas entre elementos y archivos de apoyo. Complementa el ejercicio presencial alrededor del tablero.

1. Entra a la sala del equipo

Todos los que entren con el mismo código de sala trabajan sobre el mismo tablero. Comparte el enlace con el código de sala a tus compañeros.

2. Sincronización real (Supabase)

Pega los datos de tu proyecto de Supabase para que varios participantes trabajen a la vez desde distintos computadores. Sin ellos, la sala funciona solo en este navegador y guarda localmente.
